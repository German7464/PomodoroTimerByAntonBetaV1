# Локализация интерфейса

## Поддерживаемые языки

Интерфейс использует 11 каталогов Qt с кодами BCP 47. Название в выборе языка всегда остаётся самоназванием и не переводится:

| Код | Название |
|---|---|
| `ru-RU` | Русский |
| `en-US` | English |
| `es-ES` | Español |
| `de-DE` | Deutsch |
| `fr-FR` | Français |
| `pt-BR` | Português (Brasil) |
| `zh-CN` | 中文（简体） |
| `hi-IN` | हिन्दी |
| `ar-SA` | العربية |
| `ja-JP` | 日本語 |
| `ko-KR` | 한국어 |

Русский — исходный и аварийный язык. Старый `settings.json` без поля `ui_language` мигрирует в `ru-RU`; только новая установка выбирает поддерживаемый язык Windows, а для неподдерживаемого языка также получает русский. В JSON сохраняется код, а не отображаемое название.

## Архитектура

`app/i18n.py` содержит единый `TranslationManager`, реестр языков и функции `tr()`/`trn()`. Менеджер устанавливает один составной `QTranslator`, один раз загружает русский fallback, кэширует выбранные `.qm` и штатные `qtbase_*.qm`, задаёт `QLocale` и направление `QApplication`. Отсутствующая строка сначала ищется в русском каталоге, затем Qt получает возможность использовать собственный источник; пустой элемент интерфейса не показывается.

Приложение переводит стабильные ключи контекста `PomodoroTimer`, например `timer.action.continue`, а не русские надписи или положение элемента. Параметры имеют имена (`{count}`, `{mode}`); законченные предложения не собираются из переведённых фрагментов. Для количеств используется `trn()` и plural-формы Qt: 3 русские, 6 арабских, по 2 для языков с двумя формами и по 1 для китайского, японского и корейского.

При смене языка менеджер отправляет `QEvent.LanguageChange` всем открытым верхнеуровневым окнам и сигнал `language_changed` сервисам/вложенным представлениям. Они обновляют существующие Qt-объекты на месте. `TimerEngine`, статистика, профили, секундный `QTimer`, окно виджета, меню и значок трея не пересоздаются. Новые уведомления используют текущий язык; уже показанные системные сообщения не переписываются.

Для `ar-SA` направление приложения становится `RightToLeft`; при любом другом языке восстанавливается `LeftToRight`. Направленная иконка пропуска зеркалится, универсальные иконки остаются прежними. Поля времени и цифры таймера принудительно сохраняют LTR, чтобы знак `+` и разделители не перемешивались.

Сообщения mutex и раннего запуска возникают до импорта Qt. `app/early_i18n.py` читает выбранный код из настроек и соответствующий `.ts` с русским fallback. В frozen-сборке оба механизма находят ресурсы через `sys._MEIPASS`.

## Ресурсы и внутренние идентификаторы

Исходники находятся в `assets/translations/<код>.ts`, скомпилированные каталоги — рядом как `<код>.qm`; все файлы UTF-8. PyInstaller spec включает оба вида ресурсов и штатные Qt-переводы. Типы таймера, виджета, размера, темы и эффекта хранят стабильные внутренние ID. Русские значения из старых JSON принимаются только миграцией. Имена, введённые пользователем, пользовательские темы и профили не переводятся.

Единая терминология каталога различает рабочий период, короткий/длинный отдых, продолжение работы после установленного времени, два вида отдыха сверх нормы, автоматический переход, пользовательскую тему и light/dark. Названия продукта и встроенных именных тем `Pomodoro Timer`, `Comet`, `Aurora`, `Warm` остаются именами.

Системная цепочка шрифтов: Segoe UI Variable/Segoe UI с резервами Microsoft YaHei UI, Nirmala UI, Yu Gothic UI, Meiryo UI, Malgun Gothic и Arial. Кнопки измеряют локализованные подписи через `QFontMetrics`, а адаптивные `FlowLayout` и прокрутка не уменьшают текст ради помещаемости.

## Проверка и добавление языка

```powershell
python tools/build_translations.py
python tools/build_translations.py --check-only
python -m unittest tests.test_localization -v
$env:QT_QPA_PLATFORM='windows'
python tools/capture_localization_qa.py --output build/localization-qa-windows
```

`build_translations.py` проверяет одинаковый набор ключей, пустые и незавершённые переводы, число plural-форм, именованные параметры, дубликаты, неиспользуемые ключи, ключи неправильного формата, исходные пользовательские строки в Python и оставшуюся кириллицу в нерусских каталогах. Без `--check-only` после проверки он вызывает Qt `lrelease` и пробует загрузить каждый готовый `.qm`; отдельный тест также загружает все каталоги.

Для нового языка добавьте одну запись в `SUPPORTED_LANGUAGES`, код и число plural-форм в проверяющий инструмент, полный `.ts`, затем пересоберите `.qm`, включите новый ожидаемый код в тест и выполните визуальную матрицу. Логику экранов менять не требуется. Новая пользовательская строка должна сначала получить стабильный ключ и русский текст без редактирования формулировки, затем полный перевод во всех каталогах.

`capture_localization_qa.py` создаёт для каждого языка снимки главного окна, таймера, статистики, справки, всех разделов настроек, редактора темы, виджета, трея, уведомления, диалога и обоих видов превышения. Снимки на реальном Windows Qt backend дополняют автоматические тесты, но не заменяют проверку системного DPI, ClearType и оболочки трея перед релизом.
