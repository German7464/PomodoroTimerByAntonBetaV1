# Pomodoro Timer

Pomodoro Timer - простое приложение на Python и Tkinter для работы по методу Pomodoro.
Программа помогает чередовать рабочие периоды и отдых, вести статистику, использовать профили настроек, виджет, уведомления, трей и автозапуск вместе с Windows.

## Возможности

- Pomodoro Timer с режимами `Работа`, `Короткий отдых`, `Длинный отдых`.
- Настройка времени работы, короткого отдыха и длинного отдыха.
- Длинный отдых можно включить или выключить.
- Можно выбрать формат времени:
  - `HH:MM:SS`;
  - `MM:SS`.
- Статистика за сегодня и за все время.
- Профили настроек: можно сохранять разные наборы параметров и быстро переключаться между ними.
- Плавающий виджет таймера.
- Виджет можно перемещать мышью.
- У виджета можно настроить цвет фона, цвет текста и прозрачность.
- Уведомления о завершении периода.
- Два режима уведомлений:
  - автоматический переход - уведомление показывает кнопку `Закрыть`;
  - ручной переход - уведомление показывает кнопку `Продолжить`.
- Работа в трее Windows.
- Автозапуск вместе с Windows для текущего пользователя.

## Как запустить из PyCharm

1. Откройте папку проекта `PomodoroTimerByAnton` в PyCharm.
2. Убедитесь, что выбран интерпретатор Python из `.venv`.
3. Откройте файл `main.py`.
4. Запустите `main.py` зеленой кнопкой Run или сочетанием `Shift+F10`.

## Как запустить из терминала

Откройте терминал в папке проекта и выполните:

```powershell
python main.py
```

Если используется виртуальное окружение `.venv`, сначала активируйте его:

```powershell
.venv\Scripts\activate
python main.py
```

## Зависимости

Основной интерфейс сделан на стандартном `tkinter`.

Для работы трея нужны внешние библиотеки:

- `pystray` - иконка и меню в системном трее;
- `Pillow` - создание изображения иконки для трея.

Все зависимости указаны в `requirements.txt`.

## Как установить зависимости

В терминале из папки проекта выполните:

```powershell
python -m pip install -r requirements.txt
```

## Где хранятся настройки

При запуске из PyCharm или терминала настройки, профили и статистика хранятся в папке проекта:

```text
data/settings.json
data/profiles.json
data/statistics.json
```

В собранной exe-версии программа работает в portable-режиме: данные хранятся рядом с exe:

```text
dist\PomodoroTimerByAnton\data\settings.json
dist\PomodoroTimerByAnton\data\profiles.json
dist\PomodoroTimerByAnton\data\statistics.json
```

Если программа лежит в защищенной папке, например `C:\Program Files`, Windows может запретить запись рядом с exe. В этом случае программа покажет предупреждение и временно использует fallback-папку пользователя:

```text
C:\Users\<имя_пользователя>\.pomodoro_timer_by_anton\
```

Если JSON-файл поврежден или отсутствует, программа создает рабочий файл заново и не должна падать.

## Как сбросить настройки

Чтобы сбросить основные настройки, закройте приложение и удалите файл:

```text
data/settings.json
```

При следующем запуске программа создаст настройки по умолчанию.

Чтобы сбросить профили, удалите файл:

```text
data/profiles.json
```

Чтобы сбросить статистику, можно нажать кнопку `Сбросить статистику` на вкладке `Статистика`.
Также можно закрыть приложение и удалить файл статистики из текущей папки данных:

```text
data/statistics.json
```

## Как собрать exe

Для сборки используется PyInstaller. Сначала установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

Затем выполните сборку:

```powershell
python -m PyInstaller --noconfirm --clean --onedir --windowed --name PomodoroTimerByAnton main.py
```

Готовый exe появится здесь:

```text
dist\PomodoroTimerByAnton\PomodoroTimerByAnton.exe
```

Для этого проекта сначала используется `--onedir`, потому что такой вариант надежнее для Tkinter, трея, виджета и Pillow. Вариант `--onefile` можно проверить позже отдельно.

## Portable-режим

Для переноса на другой компьютер копируйте всю папку:

```text
dist\PomodoroTimerByAnton\
```

Внутри нее должны быть:

```text
PomodoroTimerByAnton.exe
_internal\
data\
```

Одну exe без папки `_internal` переносить нельзя, потому что используется сборка `--onedir`.

Папка `data` должна лежать рядом с `PomodoroTimerByAnton.exe`. Если при первом запуске папки `data` нет, программа создаст ее сама.

Если раньше данные лежали в:

```text
C:\Users\<имя_пользователя>\.pomodoro_timer_by_anton\
```

то при первом запуске exe программа безопасно скопирует старые `settings.json`, `profiles.json` и `statistics.json` в portable-папку `data`, если там еще нет своих JSON-файлов. Старые файлы не удаляются автоматически.

## Автозапуск

Автозапуск включается на вкладке:

```text
Настройки -> Трей и автозапуск
```

Автозапуск работает только для текущего пользователя и не требует прав администратора. Программа создает ярлык в папке автозагрузки текущего пользователя.

В exe-версии автозапуск указывает на текущий файл:

```text
PomodoroTimerByAnton.exe
```

Если перенести папку программы в другое место, старый ярлык автозапуска будет указывать на старый путь. Программа покажет в настройках, что путь устарел. Чтобы обновить путь, включите автозапуск и сохраните настройки еще раз.

Если программа запущена из Python через `main.py`, автозапуск по умолчанию недоступен: он рассчитан на exe-версию.

Автозапуск учитывает два варианта:

- запуск из Python через `main.py`;
- запуск собранного `.exe`.

## Краткая инструкция для пользователя

1. Откройте приложение.
2. На вкладке `Таймер` нажмите `Старт`.
3. Работайте, пока идет рабочий период.
4. После завершения периода программа перейдет к отдыху или покажет уведомление.
5. Если включен автоматический переход, следующий период начнется сам.
6. Если включен ручной переход, нажмите `Продолжить` в уведомлении.
7. Вкладка `Настройки` позволяет менять время, формат, уведомления, виджет, профили, трей и автозапуск.
8. Вкладка `Статистика` показывает рабочее время, отдых, пропуски, сбросы и завершенные циклы.
9. Вкладка `Справка` содержит описание кнопок и режимов.
10. Если включен виджет, его можно перетащить мышью в удобное место.
