# PomodoroTimerByAnton

Современное Windows-приложение Pomodoro на Python и PySide6 Qt Widgets. Оно сочетает единый таймер, ручный учёт превышения, статистику, профили, тематизированные уведомления, системный трей и семь видов плавающего виджета.

## Возможности

- Работа, короткий и длинный отдых; настраиваемые длительности и число циклов.
- Автоматический переход или ручное ожидание «Продолжить».
- Раздельная статистика работы, отдыха, переработки и двух видов отдыха сверх нормы за сегодня и всё время.
- Темы Comet, Aurora, Warm и Пользовательская в light/dark.
- Редактор пользовательской палитры с preview, отменой, безопасным reset и проверкой контраста.
- Шесть эффектов превышения: без анимации, пульсация, scale, маячки, рамка и волна.
- Семь макетов виджета с независимыми размерами/координатами и alpha 5–100%.
- Единые доступные toggle switch для всех двоичных настроек.
- Qt-уведомление, `QSystemTrayIcon`, автозапуск HKCU и Windows mutex одного экземпляра.
- Безопасная миграция существующих `settings.json`, `profiles.json`, `statistics.json`.

## Интерфейс

Левая навигация открывает Таймер, Статистику, Настройки и Справку. Таймер остаётся главным визуальным элементом. Команды «Старт», «Пауза», «Пропустить», «Сбросить» и «Продолжить» — обычные кнопки; двоичные настройки используют округлый переключатель с положением, цветом и текстом `ВКЛ/ВЫКЛ`.

Переключатель «Тёмный режим» над таймером и аналогичный элемент в настройках используют одно поле `appearance_mode`. Темы применяются ко всем открытым окнам без перезапуска и без изменения таймера. Qt сохраняет нативную системную рамку Windows ради качественного DPI, resize и доступности.

При первом запуске главное окно занимает около 80% доступной области монитора. Размер и положение сохраняются; после смены разрешения или монитора окно возвращается в видимую область. При ширине меньше 1200 логических пикселей боковая навигация сворачивается до доступных SVG-иконок, заголовки и группы кнопок переносятся строками, а настройки и статистика переходят к одноколоночной раскладке.

Редактор темы имеет отдельную прокручиваемую палитру и закреплённые действия. Ширина кнопок определяется по реальному тексту через `QFontMetrics`, поэтому длинные русские подписи не обрезаются при DPI 100–175%. Командные кнопки дают мягкую обратную связь мышью и через `Space`/`Enter`; контрастный focus показывается только при клавиатурном управлении, а отключение движения убирает масштабирование.

## Ручной переход и превышение

При автоматическом переходе завершённый период записывается один раз, следующий запускается сразу, превышение остаётся нулевым.

При выключенном автоматическом переходе завершившийся режим не переключается: время идёт от нуля со знаком `+`, а интерфейс показывает «Переработка», «Короткий отдых сверх нормы» или «Длинный отдых сверх нормы». До «Продолжить» старт, пауза, пропуск и сброс блокируются. Кнопки главного окна, уведомления и виджета вызывают один обработчик: превышение сохраняется ровно один раз и следующий период сразу запускается.

Крестик уведомления только закрывает его; подсчёт продолжается. При выключенных уведомлениях «Продолжить» остаётся в главном окне и виджете. Штатный полный выход сохраняет уже накопленное превышение.

## Темы и эффекты

Comet — спокойная нейтральная база; Aurora — холодные сине-фиолетовые акценты; Warm — мягкие тёплые поверхности. Пользовательская тема хранит светлую и тёмную палитры отдельно. Редактор принимает `#RRGGBB`; контраст ниже 4,5:1 требует подтверждения, а повреждённые поля восстанавливаются из Comet.

Структурный QSS устанавливается один раз, а цвета переключаются через `QPalette`; видимое дерево обновляется одним проходом, скрытая страница — непосредственно перед открытием. Меню трея получает отдельные читаемые цвета в обоих режимах. Windows-заголовок запрашивает системный тёмный вариант DWM без замены нативной рамки; если конкретная версия Windows сохраняет светлый заголовок, используется её безопасный системный вид.

В «Настройки → Превышение» выбирается один основной эффект, независимое изменение цвета, область, скорость, интенсивность, разрешение движения и три цвета. Preview не меняет таймер, статистику, уведомления или alpha. Главное окно и виджет получают одну фазу; после завершения восстанавливаются цвет, размер, рамка и индикаторы.

## Плавающий виджет

Переключатель «Отображать виджет» на странице таймера управляет одним переиспользуемым окном. Крестик переводит переключатель в `ВЫКЛ`. Тип, preset/custom-размер, координаты и положение сохраняются отдельно.

- Минималистичный — время, состояние и только нужная команда продолжения.
- Компактный — состояние, время, старт/пауза.
- Расширенный — цикл и основные команды; при узкой ширине действия переносятся целиком, а «Открыть» становится доступной иконкой с подсказкой.
- Микро — минимальное время с обязательным overrun UI.
- Строка — горизонтальная компоновка.
- Кольцо — прогресс периода без значений свыше 100%.
- Табло — крупные контрастные моноширинные цифры.

Ползунок «Непрозрачность виджета» реально задаёт `setWindowOpacity()` от 0.05 до 1.0 и сохраняется с задержкой. Настройка временной непрозрачности ставит 1.0 только на время реального превышения и возвращает точное постоянное значение.

Во всех видах основная кнопка заранее учитывает полную подпись «Продолжить». В расширенном виде текстовые команды никогда не ужимаются ниже `minimumSizeHint`; минимальный пользовательский размер 330×245 раскладывает их в две строки, маленький preset использует 400×245. Переход к превышению и временная непрозрачность не пересоздают окно и не меняют его геометрию.

## Установка и запуск

Требуется Windows 10/11 и Python 3.10–3.14; разработка проверяется на Python 3.14.7.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
python main.py
```

Runtime-зависимость: `PySide6-Essentials==6.11.1` (QtCore/Gui/Widgets/Svg, LGPL option). Инструмент сборки: `PyInstaller==6.22.0`. Pillow и pystray не используются. Полные notices: `THIRD_PARTY_NOTICES.md`.

## Тесты

```powershell
$env:QT_QPA_PLATFORM='offscreen'
python -m compileall -q app tests main.py
python -m unittest discover -s tests -v
```

Тесты используют стандартный `unittest` и `PySide6.QtTest`, не открывая рабочий интерфейс. Они проверяют ядро, статистику/миграции, mutex, темы, toggle, общий кадр эффектов, семь видов, видимость и прозрачность. Реальные DPI, ClearType, системный трей и несколько мониторов остаются частью ручной release-QA.

## Сборка Windows

```powershell
python tools/generate_app_icons.py
python -m PyInstaller --noconfirm --clean PomodoroTimerByAnton.spec
.\dist\PomodoroTimerByAnton\PomodoroTimerByAnton.exe
```

Используется надёжная onedir-сборка с динамическими Qt DLL. Переносить нужно всю папку `PomodoroTimerByAnton`, а не только exe. Spec включает полный набор SVG/PNG/ICO и notices, назначает многослойный `app.ico` файлу EXE и не добавляет тесты или пользовательские JSON. Фактический состав пакетов проверяется после чистой сборки.

Оригинальный знак — оранжевый минималистичный помидор с дугой таймера. `app.svg` является источником PNG 16/20/24/32/48/64/128/256 и восьмислойного ICO; `tray.svg` упрощён для 16 px. Один AppUserModelID и одна иконка назначаются приложению, окнам, панели задач, диалогам, виджету, трею и EXE.

## Пользовательские данные

В исходном проекте JSON хранятся в `data/`. В сборке каталог создаётся рядом с exe; при отсутствии прав используется `%USERPROFILE%\.pomodoro_timer_by_anton` с предупреждением. Существующие файлы не удаляются. `statistics.json` версии 1 мигрирует в версию 2 и получает нулевые поля превышения без повторного учёта старых периодов; повреждённая статистика резервируется как `.corrupt*.bak`.

Пользовательские JSON, `.venv`, `.idea`, `build`, `dist` и кэши исключены из Git.

## Единственный экземпляр и автозапуск

`main.py` получает именованный Windows mutex до импорта Qt и настроек. Второй процесс показывает сообщение и завершает только себя. Mutex освобождается ОС даже после аварии; PID-файл не используется. Автозапуск exe настраивается для текущего пользователя в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
